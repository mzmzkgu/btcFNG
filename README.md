# btcFNG

공포탐욕지수(Fear &amp; Greed Index)와 고점 대비 낙폭(MDD)이 커질 때 역발상으로 BTC를 분할 매수하는 봇의 상태 계기판.

## 구성
- `index.html` — F&amp;G 지수 게이지, MDD 게이지(0~60%), 분할매수 진행률(`parts_used`/`division`), 평단가·현재가·누적수익·ATH·실현손익·투입원금을 표시
- `btc_fng_status.json` — 봇 실행 시 갱신되는 상태 데이터

## 전략
- 고점 대비 낙폭(MDD)이 일정 구간(30%대 1티어 공포 / 45%대 2티어 강한공포)에 들어오면 분할 매수 실행
- 총 매수 횟수(`division`)를 정해두고 공포 구간일수록 더 적극적으로 매수하는 역발상(contrarian) 구조
- 라즈베리파이 등 백엔드 봇이 실행될 때마다 상태를 git에 커밋 → 페이지는 5분마다 재조회
